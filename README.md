
## Objectives
- Analyze Amazon customer reviews.
- Perform data cleaning and preprocessing.
- Explore rating distribution.
- Analyze customer sentiment.
- Visualize insights using charts.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Findings
- Negative reviews form the largest category.
- Positive reviews represent a smaller portion.
- Neutral reviews account for the smallest category.
- The dataset contains 20,946 reviews.

## Conclusion
The analysis shows that negative reviews form the largest category in the dataset. This indicates that many customers reported negative experiences.
