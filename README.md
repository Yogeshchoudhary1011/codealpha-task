# 📊 Amazon Reviews Sentiment Analysis

## 📌 Project Overview
This project analyzes Amazon customer reviews to understand customer opinions and sentiment patterns using Python.

## 🎯 Objectives
- Analyze customer reviews.
- Explore review data and identify patterns.
- Perform Exploratory Data Analysis (EDA).
- Visualize insights from customer reviews.

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📂 Project Files
- [Amazon Reviews Dataset](Amazon_Reviews.csv)
- [Sentiment Analysis Dataset](Amazon_Reviews_Sentiment.csv)
- [EDA Notebook](EDA.ipynb)
- [Data Visualization Notebook](Data%20visualization.IPYNB)
- [Sentiment Analysis Notebook](Sentiment%20Analysis.ipynb)

## 🔍 Project Workflow
1. Data loading
2. Data cleaning and preparation
3. Exploratory Data Analysis
4. Sentiment analysis
5. Data visualization
6. Insights and interpretation

## 📈 Key Learnings
- Data cleaning and preprocessing
- Exploratory Data Analysis
- Working with Pandas
- Data visualization
- Understanding customer review sentiment
